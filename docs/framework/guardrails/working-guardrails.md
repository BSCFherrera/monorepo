# Guardrails mínimos del framework

- No usar datos sensibles o secretos en prompts.
- No asumir arquitectura o stack no documentado.
- No agregar dependencias sin aprobación.
- No avanzar en tickets ambiguos o sin aceptación verificable.
- No mergear sin validación automática y revisión humana.
- Escalar a Senior, Arquitecto o SecOps cuando haya riesgo técnico, de seguridad o de compliance.

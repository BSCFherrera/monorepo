# Prompt de escenarios Gherkin

## Incluir

- proposal / design / tasks del change (spec ya generado por opsx-propose)
- criterios de aceptación / objetivos funcionales del design
- casos happy path
- casos de error
- edge cases relevantes identificados en tasks
- datos de prueba necesarios
- idioma y keywords Gherkin (Característica, Escenario, Dado, Cuando, Entonces)

## Precondición

- El change debe tener proposal/design/tasks completos (`opsx-propose.ps1` ya ejecutado).

# Memoria del framework

## Propósito

La memoria del framework permite guardar el estado de ejecución de cada cambio y compartirlo con el repositorio para que todo el equipo vea el mismo estatus.

## Componentes

- MEMORY-SCHEMA.md: esquema y formato de memoria
- team-change-status.md: memoria compartida del equipo
- jira-issues/: snapshots descargados desde Jira

## Uso

- actualizar memoria local con framework:memory:update
- descargar Jira con framework:jira:download
- sincronizar memoria compartida con framework:memory:sync
